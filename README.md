# Takt

Кроссплатформенный менеджер задач (Windows / Linux / macOS / Android) на Python + Flet.
Работает полностью офлайн; синхронизация — по желанию: Яндекс.Диск или прямой перенос
между устройствами по QR-коду через локальную сеть.

Ритм ваших дел: повторяющиеся задачи, дедлайны, категории и подзадачи.

## Возможности

- Задачи: название, заметки, теги, приоритет, дедлайн, категория, подзадачи
- Периодичность: каждые N дней, по будням, еженедельно (выбор дней), ежемесячно
- Выполнение повторяющейся задачи переносит её на следующий срок; история выполнений копится
- Напоминания при наступлении срока (пока приложение запущено)
- Фильтры: все / сегодня / просроченные / выполненные, по категории; поиск; тёмная тема
- **Локальный режим** — без токена и без облака данные живут только на устройстве
- **Синхронизация через Яндекс.Диск** — журнал изменений, офлайн-работа, LWW-слияние
- **Перенос по QR (без облака)** — ПК ↔ телефон через Wi-Fi, с предпросмотром разницы данных
- **Обновления из GitHub-репозитория** — проверка релизов, скачивание и запуск установщика

## Архитектура

```
takt/
  core/            # не зависит от UI и облака
    models.py      # Task, Category, Recurrence
    recurrence.py  # расчёт следующего вхождения
    store.py       # SQLite + журнал изменений, LWW-слияние, экспорт состояния
    scheduler.py   # фоновые напоминания
  sync/            # облачная синхронизация
    base.py        # SyncProvider — интерфейс провайдера
    yandex.py      # Яндекс.Диск REST API (OAuth)
    engine.py      # обмен журналами devices/{device_id}.jsonl
  transfer.py      # перенос по QR/LAN: сервер, QR, diff, применение
  update.py        # обновления из GitHub releases
  ui/              # Flet-интерфейс
installer.py       # установщик Windows (GUI + тихий режим /S)
build.py           # сборка дистрибутивов
tests/             # юнит-тесты
main.py            # точка входа
```

**Синхронизация (облако).** Каждое устройство пишет только свой файл
`devices/{id}.jsonl`, конфликтов записи нет. Чужие журналы применяются идемпотентно;
более поздняя правка побеждает (LWW). Удаления — tombstone. Новое облако = реализация
`SyncProvider` (4 метода).

**Перенос по QR (без облака).** Устройство-источник поднимает временный HTTP-сервер
в локальной сети и показывает QR со ссылкой (одноразовый токен, TTL 5 минут).
Телефон сканирует QR любой камерой → браузер → «Скачать файл данных» → в приложении
«Принять → Из файла». Либо «Принять → По ссылке» (вставить URL из QR). Перед применением
показывается разница: новые / изменённые / удалённые; более новые правки принимающей
стороны сохраняются. Встроенный сканер камеры — в плане развития (нужен нативный плагин).

**Данные.** Локально: `~/.takt/takt.db` (переопределяется `TAKT_HOME`).
На Диске: папка `Takt/devices/`.

## Запуск на ПК

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # Windows
# .venv/bin/pip install -r requirements.txt     # Linux/macOS

.venv/Scripts/python main.py        # нативное окно
.venv/Scripts/python main.py --web  # веб-версия на http://127.0.0.1:8550
```

## Готовые сборки Windows (dist/)

```bash
.venv/Scripts/python build.py
```

- `Takt-Portable.exe` — standalone, ничего не устанавливает
- `Takt-Setup.exe` — установщик: каталог, ярлыки, запись в «Установка и удаление программ»,
  деинсталлятор. Тихий режим: `Takt-Setup.exe /S [/DIR=каталог]` (используется автообновлением)

## Тесты

```bash
.venv/Scripts/python -m unittest discover -s tests -v
```

## Яндекс.Диск: настройка синхронизации

1. Приложение на https://oauth.yandex.ru/client/new — платформа «Веб-сервисы»,
   доступы к Диску, redirect URI `https://oauth.yandex.ru/verification_code`.
2. Токен: `https://oauth.yandex.ru/authorize?response_type=token&client_id=<CLIENT_ID>`.
3. В приложении: Настройки → токен → «Синхронизировать». На втором устройстве тот же токен.

## Обновления из GitHub

Механизм смотрит `releases/latest` репозитория, указанного в Настройках (`owner/name`),
сравнивает версии и предлагает обновиться. Порядок публикации релиза:

1. Создайте репозиторий (например `takt`) и запушьте код с тегами (`git push --tags`).
2. Соберите `build.py` → получите `Takt-Setup.exe` и `Takt-Portable.exe`.
3. Создайте GitHub Release с тегом `v0.2.0` (версия = тег без `v`), приложите
   `Takt-Setup.exe` (предпочтительно) и/или `Takt-Portable.exe`, опишите изменения.
4. В приложении укажите `owner/takt` в Настройках → Обновления. Автопроверка при старте —
   галочка там же.

Пока репозиторий не создан, проверка честно сообщает об этом и не мешает работе.

## Сборка под Android

Требуется Flutter SDK и Android SDK:

```bash
.venv/Scripts/pip install flet[all]
.venv/Scripts/flet build apk
```

APK в `build/apk`. Ограничения: напоминания пока приложение запущено; встроенного
сканера QR нет — используйте камеру телефона + «Принять из файла/по ссылке».
